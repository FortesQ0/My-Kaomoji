## ✦ Что такое My Kaomoji?

**My Kaomoji** — Android-приложение для коллекции японских текстовых смайликов каомодзи. Выбирайте настроение, находите подходящий символ и вставляйте его в сообщения без лишних действий.

## Возможности

- **Большая библиотека.** Каомодзи распределены по категориям, чтобы нужная эмоция находилась быстрее.
- **Поиск и фильтры.** Находите подходящие варианты по настроению.
- **Свои любимчики.** Добавляйте каомодзи в избранное долгим нажатием.
- **Умная клавиатура.** Используйте каомодзи прямо в других приложениях; быстрый ряд показывает избранные и часто используемые варианты.
- **Виджет на рабочем столе.** Держите любимые каомодзи под рукой и копируйте их одним нажатием.
- **RU / EN.** Переключайте язык интерфейса одним касанием.
- **Настройка внешнего вида.** Выбирайте акцент и режим оформления.
- **Локальная библиотека.** Коллекция и пользовательские настройки хранятся в приложении.

## Начало работы

### Для пользователей

Установите APK, если он предоставлен в разделе [Releases](../../releases). Если релиз пока не опубликован, воспользуйтесь инструкцией для сборки ниже.

### Для разработчиков

**Понадобится:** Android Studio Ladybug или новее и JDK 17.

1. Склонируйте репозиторий.
   ```bash
   git clone https://github.com/FortesQ0/My-Kaoji.git
   ```
2. Откройте проект в Android Studio.
3. Дождитесь завершения Gradle Sync.
4. Запустите конфигурацию `app` на устройстве или эмуляторе.

Параметры сборки: `minSdk 28` (Android 9 и новее), `targetSdk 35`, Kotlin и Jetpack Compose.

## Как включить клавиатуру

1. Откройте **Настройки Android → Система → Язык и ввод → Экранная клавиатура**.
2. Перейдите в управление клавиатурами и включите **«My Kaomoji»**.
3. В поле ввода нажмите переключатель клавиатуры и выберите «My Kaomoji».

Клавиатура запоминает последнюю выбранную категорию. После вставки каомодзи она может возвращаться к предыдущей клавиатуре — это поведение настраивается в параметрах приложения.

## Как добавить виджет

1. Удерживайте пустое место на рабочем столе.
2. Откройте раздел **Виджеты** и Находите **My Kaomoji**.
3. Разместите виджет и нажимайте на каомодзи, чтобы копировать их.

## Управление

| Действие | Результат |
| --- | --- |
| Нажать на карточку в приложении | Скопировать каомодзи |
| Нажать на карточку на клавиатуре | Вставить каомодзи |
| Удерживать карточку | Добавить в избранное или убрать из него |
| Нажать RU / EN | Переключить язык |

## Проверка библиотеки

Коллекция находится в `app/src/main/assets/komoji.json`. Для проверки данных запустите тесты:

```bash
./gradlew test
```

В проекте также есть инструменты для проверки и перекатегоризации коллекции. Сначала можно сформировать отчёт без изменения файла:

```bash
python3 tools/recategorize.py --dry
```

Флаг `--write` записывает результат в JSON, поэтому перед его использованием стоит проверить отчёт и сохранить изменения в Git.
