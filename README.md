## 📱 Как это работает

**01 — Найди.** Выбери настроение, категорию или воспользуйся поиском.

**02 — Сохрани.** Добавь самые любимые каомодзи в избранное.

**03 — Поделись.** Нажми на символ, чтобы скопировать его в приложении или вставить с клавиатуры.

> (っ˘ω˘ς ) Твои эмоции. Твой стиль. Всегда под рукой.

## 🚀 Начать пользоваться

Если APK опубликован, загляни в раздел [**Releases**](../../releases). Если релиза пока нет, приложение можно собрать из исходного кода по инструкции ниже.

### Подключение клавиатуры

1. Открой **Настройки Android → Система → Язык и ввод → Экранная клавиатура**.
2. Найди управление клавиатурами и включи **My Kaomoji**.
3. В любом поле ввода переключись на **My Kaomoji**.

### Добавление виджета

1. Удерживай пустое место на главном экране.
2. Открой **Виджеты** и найди **My Kaomoji**.
3. Размести виджет — теперь любимые каомодзи можно копировать одним нажатием.

## 🛠️ Техническая часть

<details>
<summary><strong>Стек и возможности проекта</strong></summary>

- **Язык:** Kotlin
- **Интерфейс:** Jetpack Compose и Material 3
- **Платформа:** Android
- **Хранение настроек:** DataStore
- **Виджет:** Glance AppWidget
- **Сериализация:** Kotlinx Serialization
- **Тестирование:** JUnit
- **Шрифт:** Onest

</details>

<details>
<summary><strong>Сборка из исходного кода</strong></summary>

**Понадобится:** Android Studio Ladybug или новее и JDK 17.

1. Клонируй репозиторий:

   ```bash
   git clone https://github.com/FortesQ0/My-Kaomoji.git
   ```

2. Открой проект в Android Studio.
3. Дождись завершения Gradle Sync.
4. Запусти конфигурацию `app` на устройстве или эмуляторе.

Параметры проекта: `minSdk 28` (Android 9+), `targetSdk 35`.

</details>

<details>
<summary><strong>Проверка коллекции и тесты</strong></summary>

Библиотека каомодзи находится в `app/src/main/assets/komoji.json`.

Запуск тестов:

```bash
./gradlew test
```

Сформировать отчёт перекатегоризации без изменения файла:

```bash
python3 tools/recategorize.py --dry
```

Флаг `--write` записывает изменения в JSON. Перед его использованием проверь отчёт и сохрани изменения в Git.

</details>

<details>
<summary><strong>Структура проекта</strong></summary>

```text
app/src/main/
├── assets/       # библиотека каомодзи
├── java/         # интерфейс и логика приложения
└── res/          # ресурсы и шрифты
tools/            # инструменты обработки коллекции
docs/             # сайт и графические материалы
```

</details>
